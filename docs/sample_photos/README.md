# Sample photos

22 test photos used in the notebook's live run and in the emulator gallery.
None of them were used to train the installed model: they come from the held-out test split, plus the validation split where the test split had too few sessions.

- `tomato_*`, `banana_*`, `other_produce_*`: from **AgriFreshNET** (Risdin, F., Salauddin, H., Tufa, T. A., & Hossain, M. J., 2026, Mendeley Data, https://doi.org/10.17632/42m5tb7yv9.1), licensed **CC BY 4.0**. Copied unchanged except for the file names.
- `quality_too_dark.jpg`, `quality_blurry.jpg`: an AgriFreshNET tomato photo, darkened or blurred to demonstrate the quality check.

File names give the dataset stage (1 fresh, 2 semi-fresh, 3 rotten), **not** what the app predicts.
